# Лабораторная работа №5

Основная работа находится в файле `lab5_sequence_analysis.ipynb`.

Структура:

- `data/` - исходный Online Retail в CSV и подготовленные CSV.
- `outputs/` - графики из notebook.
- `requirements.txt` - библиотеки для запуска.

Запуск:

```powershell
python -m pip install -r requirements.txt
jupyter notebook lab5.ipynb
```
